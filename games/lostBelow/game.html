Règles du jeu

Objectif : Explorer la grotte et trouver la ou les SORTIES avant que le paquet de cartes ne soit épuisé.

Conditions : Tous les joueurs encore vivants doivent atteindre UNE des sorties pour gagner.

Évènements : À chaque fin de tour, une carte évènement est tirée (Séisme, Effondrement, Obscurité...).

Points d'Action (AP) : Chaque tour, vous recevez des points d'action (🟠 dans le HUD).

Révéler : Cliquez sur une tuile à côté d'un point doré (🟠) pour poser une nouvelle tuile (1 AP). Si un passage est ouvert, vous vous y déplacez automatiquement !

Déplacement : Cliquez sur une case déjà révélée pour vous y rendre (1 AP).

Santé (HP) : Les traits rouges indiquent votre vie. À 0, vous mourez...

Étages (Layer) : Certaines tuiles sont des escaliers (⬆️/⬇️). Elles permettent de changer de niveau. Le niveau actuel est affiché dans le HUD.

Coopération : Plusieurs joueurs peuvent occuper la même case. L'entraide est la clé !

Séisme : Les secousses font s'écrouler les murs. Certains passages peuvent s'ouvrir ou se fermer.

Effondrement : Des rochers tombent du plafond. Les joueurs dans la zone perdent 1 HP ou un nouveau passage s'ouvre !

Obscurité : Les lampes vacillent. Seule la zone autour des joueurs reste visible pendant 2 tours.

Éboulement : Un amas de pierres bloque un ou plusieurs passages de la tuile.

Courant d'Air : Un vent glacial souffle dans les tunnels. Les joueurs dans la zone perdent 1 AP à leur prochain tour.
